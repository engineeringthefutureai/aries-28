# Part: Cable brace

## Purpose & role
Holds Ethernet runs in tidy parallel bundles and parks each cable's individually-adjustable service loop. The service-loop function is what lets a board type be swapped (its jack position differs) by adjusting one cable's slack rather than re-running cable — supporting node interchangeability without a harness rebuild.
